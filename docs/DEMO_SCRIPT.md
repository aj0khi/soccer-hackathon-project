# Second Story Demo Script

Target length: 90-110 seconds

## 0:00-0:10 — The problem

Open the live studio view.

Say: "A scoreline tells us what happened. Second Story explains what the match is becoming."

Point to the synthetic match label and the live event count.

## 0:10-0:25 — Bring in data

Open **Data** and choose **Run momentum scenario**.

Say: "This is a repeatable synthetic event stream. It contains passes, pressure, possession changes, shots, and a goal, with a deliberate momentum shift."

Show the dataset profile and canonical event count.

## 0:25-0:40 — Make the data meaningful

Point to the derived match state.

Say: "Before generating a story, the pipeline calculates control, danger, rhythm, chaos, pressure, possession, shots, and expected goals. Incomplete events are rejected with reasons instead of being invented."

## 0:40-0:58 — Reveal the second story

Return to the main view.

Say: "The obvious story is possession. The evidence-backed story is different: one team controls the ball while the other creates the danger."

Point to confidence, the evidence bullets, and the supporting-event count.

## 0:58-1:12 — Show the match memory

Point to the event timeline and decision window.

Say: "The match remembers its own pattern. Pressure, recoveries, shots, and the turning point are connected instead of shown as isolated statistics."

## 1:12-1:27 — Personalize the same truth

Switch between **Studio**, **Fan Lens**, and **Player Focus**.

Say: "The intelligence stays grounded in the same events, but the experience changes: deep evidence for a studio, plain language for a fan, and a player-centered read for an individual supporter."

## 1:27-1:35 — Close

Say: "Second Story turns synthetic football events into an explainable, personalized story a broadcaster can use and a fan can understand."

## Recording checklist

- Use only synthetic event data.
- Keep the browser URL and project UI visible.
- Record with system audio muted unless all audio is original or licensed.
- Keep the final video below two minutes.
- Show the GitHub repository and testing instructions in the submission materials.
