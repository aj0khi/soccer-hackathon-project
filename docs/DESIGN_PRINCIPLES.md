# Design Principles

Second Story uses a broadcast-control-room visual language: dense enough for a studio, calm enough for a fan, and explicit enough for an evaluator.

## Applied principles

- **Hierarchy before decoration:** one live interpretation leads, evidence supports it, and secondary metrics stay subordinate.
- **Motion with purpose:** entrance, live pulse, signal scan, panel entry, and timeline stagger communicate state or focus.
- **Evidence is visible:** claims open into event-linked audit trails instead of hiding behind generic AI language.
- **Responsive by default:** content reflows at narrow widths and avoids horizontal scrolling.
- **Accessible state:** live regions, logical headings, clear button labels, focusable temporary panels, contrast-conscious color, and reduced-motion handling.
- **One truth, many renderings:** Studio, Fan Lens, Player Focus, recap, and language modes share the same validated insight.
- **Synthetic-data honesty:** model outputs are labeled as synthetic, illustrative, or provider-neutral wherever real feeds are not connected.
